# Editorial link

Native text link used for album, chapter and workshop detail calls to action. Receives a destination, visible slot label and optional layout class. Owns the shared uppercase body typography, accent color, decorative right arrow and pen-stroke underline spanning label and arrow.

The underline appears only on hover or keyboard focus; retain the global visible focus outline and a minimum 44px link height. The arrow is hidden from assistive technology. No JavaScript, content lookup or routing logic. Consumers own the destination, wording and surrounding spacing.
