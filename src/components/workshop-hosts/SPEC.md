# Workshop hosts

Displays one or two resolved existing AuthorProfile records supplied by assembly, in authored order. Compact mode is used on workshop tickets; full mode provides a heading and larger portraits on detail pages. Names and portraits stay canonical in the existing author registry; workshop records reference hostIds, never duplicate profile data. Avoid article-specific “O autorovi” headings in this context. Portraits are decorative beside the visible names. Optional links use only a profile's real aboutHref. No content queries or JavaScript.
