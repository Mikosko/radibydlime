# Top navigation

TopNavigation owns the canonical homepage logo link and the seven shared routes: Úvod, Náš příběh, Kapitoly (including project details), Galerie, Dílny, Inzerce and Kontakt. Build-time pathname matching sets `aria-current="page"` and the accent underline. Reuse BrandMark and existing decorative assets with empty alt text.

Desktop (1024px and above) retains the horizontal navigation and handwritten hop annotation. Below that breakpoint, the enhanced header pairs the logo with a decorative hop and a 48px hamburger button. The owner’s `src/assets/inspiration/MENU.png` reference informs the right-side paper drawer, oversized spaced links, quiet divider, dim backdrop, logo, close icon and botanical/handwritten footer; the inspiration file is not a production asset.

A small framework-free script opens a native modal dialog. Its panel slides from the right, with scrollable content on short screens. The browser makes the background inert and contains keyboard focus; focus starts at the close button. Trigger state uses aria-controls/aria-expanded. Close via the explicit button, Escape, outside-panel click, route selection or resizing to desktop. Restore document scrolling and focus to the trigger on dismissal; preserve the page scroll position. Reduced-motion preference removes transitions. Links stay native, with existing focus styles and a visible active state.

Progressive enhancement: without JavaScript the ordinary navigation remains visible and wraps beneath the logo; the unusable hamburger stays hidden. The closed dialog is not focusable. No framework, remote requests, search, accounts or new routing are introduced.
