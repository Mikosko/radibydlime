# Top navigation

`TopNavigation.astro` renders the shared static site header. Its homepage link pairs the decorative estate illustration from `src/assets/images/logo-house.png` with the reusable [BrandMark](../brand-mark/SPEC.md) and the short thematic line beneath it. The link exposes one accessible brand label without making its decoration semantic. It also exposes one semantic primary navigation landmark. Its labels establish the intended information architecture: Úvod, Náš příběh, Kapitoly, Zápisky, Dílny, Inzerce and Kontakt.

Úvod links to the landing page and Kapitoly links to the existing Projects section. Until their public routes exist, the remaining labels intentionally use blank placeholder links and must be replaced with real destinations when those sections are implemented. The active implemented destination is derived from the built route and expressed with `aria-current="page"` plus a visible earthy underline.

The wide composition uses the paired logo, centered navigation, and the real handwritten phrase “Dobré věci rostou pomalu.” beside a decorative hop drawing derived from the approved inspiration. On smaller screens the grid reflows without a menu toggle or client JavaScript, and the annotation disappears before it competes with navigation. The component follows the shared typography roles and color tokens; it does not own page-specific navigation or breadcrumbs.
