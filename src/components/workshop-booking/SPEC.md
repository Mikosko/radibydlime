# Workshop booking

Receives a validated Workshop record from page assembly. Availability counts remain in the content data but are not displayed. Open events show a mailto reservation request; full events offer a waiting-list enquiry; preparing events offer an expression of interest. Ended events expose no enquiry action. Links include stable ID, title and scheduled date and request name/party size. Copy explicitly requires personal confirmation. Counts are manually authored, not live inventory; clicking never changes them. No form submission, backend, payment or client script.

Standalone “Termín připravujeme”, “Obsazeno” and “Proběhlo” labels are omitted. Event state still controls the enquiry action; ended events render nothing.
