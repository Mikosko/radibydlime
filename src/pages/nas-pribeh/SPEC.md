# Our story page

`/nas-pribeh/` is a static Czech introduction to the family/estate website. It follows the owner-supplied September 16 about-page inspiration: a framed photo beside editorial introduction, a small paper note, four undated stages, a textured values section, and a contact invitation in the shared `footer-intro` slot. The header and footer link to this route and primary navigation marks it current.

Initial copy is editable introductory draft text based on the established restoration, DIY, garden and family themes. Do not invent names, family composition, acquisition dates or historical milestones from the mockup. The existing generated courtyard photograph is explicitly captioned as illustrative, not evidence of the actual estate; replace it when approved real photography is available.

All wording remains HTML. Use existing local authored assets and typography tokens, responsive grids, one h1, sequential headings, and empty alt/aria-hidden for decoration. The photo has informative alt text. The page requires no client JavaScript, external requests at build time, new content models or runtime service. Contact and chapter links point to existing routes.
